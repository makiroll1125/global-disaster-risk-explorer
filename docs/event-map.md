# Daily event map

The default **Disaster locations** map uses a neutral fill and thin borders for every country. Color identifies event type. The optional **Country impacts** choropleth hides event markers and gives polygon color a separate quantitative meaning. Choose **Animated timeline**, select the map's year range, and press **Play**. A daily histogram uses the same hazard colors as the map pins, pulses, type-ranking bars, and streamgraph. The day slider and previous/next buttons support keyboard navigation; the year slider jumps to January 1. Clicking the histogram seeks to a day. Playback uses elapsed real time: **Fast = 4 seconds/year**, **Normal = 12 seconds/year**, **Slow = 24 seconds/year**, with leap years taking the same duration. It stops at the selected end date or export cutoff and pauses when the tab is hidden. Optional **Skip quiet gaps** compresses gaps longer than 30 days, stopping on the final recorded date; its label/status explicitly distinguish that compressed time scale from default calendar playback.

Global hazard filtering supports a union of types: Earthquake + Tsunami includes both types, intersected with the selected geography and each view's own dates. All selects every recorded type; None creates an explicit empty selection. The navbar checkbox menu and disaster-ranking bars share this selection. Clicking a checked type excludes only that type, including when all types are selected; clicking it again restores it. Use None to begin a small subset. Ranking bars retain all types under the selected geography/date range so further types can be added. The ranking viewport is 410px high for either tab and scrolls internally. [Hazard colors and descriptions](hazard-encoding.md) documents the shared palette and terminology sources. Map-specific spatial/date selection, sparse-hazard playback, grouping, impact sizing, and source inspection are documented in [map exploration](map-exploration.md). Navbar controls use fixed popovers with search and keyboard access; their underlying selects retain the data state. Opening menus and changing values preserves the current reading position.

Filled markers use the source's latitude/longitude pair. Hollow markers use a country geometry's reference point and can be hidden with **Include country reference points**. Records with neither a valid coordinate pair nor a mapped country reference point cannot be placed. No coordinates are geocoded or randomly generated. Source coordinates are reported locations and may represent a disaster origin rather than every affected locality.

The preparation script preserves location text and valid coordinate pairs in JSON/CSV. There are **1,864** source-located records out of **10,896**. Zero latitude/longitude is valid; missing or out-of-range pairs remain null. Source totals, event identifiers, and the original broad classifications are preserved.

Daily replay requires a valid year/month/day and excludes dates after **15 September 2026**. **9,331** records qualify before geographic placement. Missing or invalid dates are never assigned to January 1 or the first of a month. Those records remain in selected-period markers where geographically placeable, summaries, other charts, and downloads. The animated histogram and date slider span the full map period, narrowed by any local date interval. Every matching dated record remains in the histogram regardless of the cursor's year. Clicking a bar seeks to its exact recorded day, including all records sharing that day. Animated markers stay for **2.5 real seconds**, fading during the final **0.7 seconds**, then leave the map. Expiry continues while paused; it never removes source records from the histogram or cumulative exploration summaries/list. Manual seeking clears the previous trail and reveals starts on the requested date. Selected period mode retains its static overview of all matching records. In the separate Country impacts view, replay shading shows the selected records accumulated through the current date, with one fixed scale based on full-period country totals across the map range.

New starts pulse simultaneously if they share a date. Each ring expands to **38 screen pixels** over **1 second** and fades. Pins stay at a three-pixel radius while zooming; their positions follow the map projection and pan/zoom transform. Rings indicate starts, not a hazard footprint, intensity, speed, or affected area. Reduced-motion users receive static pins without expanding rings or opacity animation; the markers still leave after 2.5 seconds.

Playback batches all source starts crossed between animation frames, so frames spanning multiple days do not drop records. Projection and scope data are cached, date lookups use binary search, and the timeline is built only when its scope changes. Panning moves the existing layers without rebuilding clusters or exploration details. Cluster SVG elements are reused; the exploration panel defers its charts/list until opened and refreshes at most five times per second during playback. The real-clock and performance checks are in `tests/playback_performance_check.py`.

The 14 broad source groups are refined into **34 recorded display categories** using explicit subtypes in `js/hazards.js`. For example, tsunami separates from earthquake, tropical cyclone becomes Hurricane / typhoon, and wet/dry avalanches share Avalanche. Hurricanes, typhoons, and other tropical cyclones remain one category because the subtype does not reliably separate them. Subsidence is not relabeled as sinkhole. Firestorm and sinkhole appear as unavailable options and zero-count legend entries because neither is explicitly classified in the source. Wildfire remains available. Filtered downloads include original type, subtype, display type, dates, coordinates, and location text.

**Expand map** fills the browser viewport using an in-page layout. Compare Impacts moves below the map in normal document flow. The button or Escape restores the two-column layout while retaining filters, playback date, and zoom. Narrow screens retain a scrollable layout when all explanatory controls cannot fit in one viewport.
